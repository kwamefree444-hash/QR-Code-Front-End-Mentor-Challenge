1. How did using Figma designs as references affect your coding process?

   Using Figma designs as references helped me understand how the website should look before I started coding. It gave me a visual guide for spacing, colors, sizing, and alignment, making it easier to plan my HTML and CSS.

2. What challenges did you encounter when aligning your code with the design specifications?

   One of my biggest challenges was getting elements properly centered and aligned on the webpage. I also had some difficulty understanding how different container sizes, margins, and Flexbox properties affected the overall layout.

3. How can the feedback and community resources on Frontend Mentor help you improve as a developer?

   Frontend Mentor allows me to compare my work with other developers and receive feedback on areas I can improve. Community resources also help me learn different coding techniques, solve problems, and become more confident in my HTML and CSS skills.
